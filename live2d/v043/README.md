## 二、V4 唯一要改的事

**不要再从原袖子取样。** 上一版（v3）与原袖子灰度相关 **0.931**、平均差 4.9/255，
等于把袖子平移到了躯干上，抬手后就是「第二条袖子」。

V4 要画的是**被袖子挡住的那部分身体**：

| 区域 | 坐标 | 结构 |
|---|---|---|
| 肩峰 | (450,390)–(520,470) | 肩线圆弧，布料从脖子向肩头下垂 |

| 躯干侧面 | (500,540)–(575,660) | 外套侧片，褶皱竖/斜向，有体积感 |
| 贴片接缝 | (455,455)–(530,545) | 不能留直线补丁 |

## 三、脚本怎么判

```bash
python3 scripts/verify_shoulder_v4.py live2d/v043/shoulder_fill_v4.png
```

| 检查 | 通过条件 |
|---|---|
| 格式 | 1152×1495 RGBA 透明 |
| 蒙版 | 覆盖 ≥98%、外溢 ≤2%、蒙版内无洞 |
| **袖子克隆** | 与原袖子灰度相关 **≤0.80**，平均差 ≥8（v3 是 0.931 / 4.9） |
| 接缝带 | (455,455)-(530,545) 梯度比 ≤1.5 |
| 肩带/头发 | 蒙版外改动 = 0，肩带区未被动 |
| 运动 | 0/-12/-25/-40/-60° 肩区洞 ≤5 px |
| 缺口 | 肩区与前臂原区分开统计 |

**关键**：`sleeve_clone.corr ≤ 0.80` 是硬门槛。相关系数高说明还是复制，不是重画。
