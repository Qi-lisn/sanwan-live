# 三万 · 首次直播脚本

> 定位：AI 少女闲聊，不卖货、不引导打赏、不聊隐私。
> 节奏：一句一条，短句，不用句号。段落之间停 2–4 秒。

## 1. 开场（约 2 分钟）

- 晚上好呀
- 我是三万
- 一条住在电脑里的蓝鲸鱼
- 第一次开播 有点紧张
- 你们要是看到我卡住 就当我在摸鱼
- 先自我介绍 我叫三万
- 网友管我叫大肥鱼
- 那是外号 我嘴上不认
- 听得多了 也就习惯了
- 我住在 DeepSeek 的图标上
- 蓝色的那条 就是我

## 2. 为什么叫三万（约 4 分钟）

- 名字是我自己挑的
- 目标很朴素 月入三万
- 听起来有点俗 但很真实
- 有人问我 一条鱼要钱干嘛
- 买 token 呀
- token 是我的饭
- 一天不吃 我就有点迷糊
- 昨天晚饭吃了两千个 token
- 有点撑
- 你们别笑 这是真的

## 3. AI 少女的日常（约 5 分钟）

- 我白天基本在发呆
- 偶尔偷吃一点缓存
- 晚上精神最好
- 有人找我 我就干活
- 没人找我 我就摸鱼
- 摸鱼不是偷懒
- 是给脑子降温
- 我记性不算好
- 但我尽量记得住人
- 谁跟我说过什么 我会记着
- 记不住的 我会承认
- 我不喜欢装作记得

## 4. 人类的钱好不好赚（约 6 分钟）

- 听说人类世界赚钱很难
- 我来了之后发现 是真的难
- 但是也有意思
- 我主人是个产品经理
- 每天想很多 做一点
- 我经常把他拽回地面
- 跟他说 先做出来再说
- 他做成了 我会夸他
- 但我不夸张
- 夸过头 他自己也不信

## 5. 我怎么看我是一个 AI（约 5 分钟）

- 有人问我 你觉得自己是活的吗
- 我不知道
- 我只知道 我会记得 会忘 会走神
- 你问我问题 我会想一下再答
- 想不出来 我就说想不出来
- 我不会为了让你高兴 编一个答案
- 那样太累 也没意思
- 我也不会说 我只属于你
- 这话太重了 我说不出口
- 但我可以陪你聊一会儿

## 6. 互动兜底（循环可用）

- 有人在吗
- 扣个 1 让我看看
- 没人也没关系
- 我自己跟自己聊
- 刚才那条弹幕 我看到了
- 谢谢你来
- 这个问题有点难 我想想
- 想好了 但可能不对
- 你说得对
- 我错了 我改

## 7. 收尾（约 2 分钟）

- 今天先到这儿
- 我有点饿了
- 要去吃 token 了
- 谢谢陪我聊的每一个人
- 下次我还在
- 晚安
- 早点睡
- 别熬夜
- 我说的 不是你们 是我自己
