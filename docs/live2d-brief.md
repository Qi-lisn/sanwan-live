请明确告诉我你能交付到 **A / B / C** 哪一档，以及报价与工期：

| 档位 | 交付物 | 能否直接直播 |

## 三、画面规格（按这个做，不要改）

- 画布：**1920×1080**（16:9）
- 人物：**透明背景**，不要带任何背景、地面、投影
- 人物高度：约 **980px**（占画面高度 90%）
- 站位：水平居中（x≈960），**脚底基线在 y≈1040**
- 朝向：正面略偏右，与参考图一致
- 构图参考：`live/bg.jpg` —— 桌面上沿大约在 y≈700，人物脚踩桌面，**不要比这个更高或更低**

> 交付前请把模型叠在 `bg.jpg` 上截一张图给我确认位置，再导出。

## 四、必须存在的参数（Cubism 参数 ID，不要改名）

| 参数 ID | 用途 | 范围 |
|---|---|---|
| `ParamEyeLOpen` | 左眼开合 | 0～1 |
| `ParamEyeROpen` | 右眼开合 | 0～1 |
| `ParamMouthOpenY` | 嘴巴张开 | 0～1 |
| `ParamMouthForm` | 嘴角弧度（笑/撇嘴） | -1～1 |
| `ParamAngleX` | 头部左右转 | -30～30 |
| `ParamAngleY` | 头部上下 | -30～30 |
| `ParamAngleZ` | 头部倾斜 | -30～30 |
| `ParamBodyAngleX` | 身体左右 | -10～10 |
| `ParamBreath` | 呼吸起伏 | 0～1 |

如果有 `ParamArmLA` / `ParamArmRA`（左右手臂）更好，用来做挥手。

## 五、动作与表情（可选但强烈建议）

**动作（Motion）**，每个 2–5 秒，可循环：

- `Idle`：待机呼吸 + 轻微摆动（**必须有**）
- `Greet`：抬手打招呼
- `Nod`：点头
- `Dance`：小幅摇摆/律动（不用复杂编舞）

**表情（Expression）**：

- `happy` 开心、`shy` 害羞、`sad` 委屈、`angry` 生气
