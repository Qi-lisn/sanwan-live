# 肩部补绘验收流程（仅肩部）

收到 `shoulder_fill.png` 后放这里：

```
live2d/v04_project/layers/shoulder_fill.png
```

然后运行：

```bash
python3 live2d/tools/verify_shoulder.py
```

## 基准（收图前已核对）

| 项 | 值 |
|---|---|
| 蒙版像素 | 18,534 |
| 蒙版 bbox | (404,376)-(573,805) |
| `torso_base.png` 在该区域 | 全部透明（18,534 px 全空） |
| 母版在该区域 | 全部不透明（18,534 px） |

也就是说：**这块缺口的边界是精确的**，多一个像素都不该画。

## 脚本会做的 6 项检查

| # | 检查 | 通过条件 |
|---|---|---|
| 1 | 文件格式 | 1152×1495、RGBA、含透明通道 |
| 2 | 与蒙版匹配 | 蒙版覆盖率 ≥98%、溢出 ≤5%、IoU ≥0.9 |
| 3 | 叠加无洞 | 蒙版区域内无透明像素 |
| 4 | 边缘连续 | 补绘区与周边色差 <45/255（无明显接缝） |
| 5 | 材质丰富度 | 补绘区梯度 ≥ 周边 45%（防平涂/模糊） |
| 6 | 关节合成 | 0/-12/-25/-40/-60° 时肩区空洞 = 0 |
| 7 | 其他部位 | 蒙版与手臂之外，与母版差异 ≤2 |

输出：`tests/shoulder_verify/report.json`、`report.md`、5 张角度合成图。

## 自检记录

用一张纯色假图跑过一次，脚本正确判为「未通过」：

- 覆盖率 100% ✅、无洞 ✅、关节空洞 0 ✅
- 边缘色差 92.8 ❌、材质梯度比 0.0 ❌ → 抓到「平涂填充」

说明检查不是只看「有没有像素」，而是看**画得对不对**。

## 若未通过

会明确给出：缺多少像素、溢出了哪些位置、色差多少、哪个角度露洞，以及需要退回重画的区域截图。
不合格不会进 Cubism。
