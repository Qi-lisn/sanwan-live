1. 旧底图和真实手臂的图层次序将影响白缝是否完全消失，静态合成不代表 60° 抬臂验收通过。
2. 下缘衔接由现有像素和渐变加工完成，存在缺少真实服装皱褶的风险。
3. 按用户指示 y>760 完全透明；如果实际衣摆需要延伸到 y790，须先明确重设美术区域，而不是悄悄增加新像素。
