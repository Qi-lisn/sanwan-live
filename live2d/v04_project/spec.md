## 蒙版来源与面积

| 蒙版 | 面积 | 生成方法 |
|---|---|---|
| 肩部 | **18,534 px** | 0/-12/-25/-40/-60° 空洞 ∩ 躯干轮廓（身体 + 肘以上手臂，闭运算补形） |
| 肘部 | **567 px** | ±25/45° 空洞 ∩ 肘点 55px 圆内 |
| 腕部 | **1,193 px** | ±15° 空洞 ∩ 腕点 45px 圆内，膨胀 2px |

> 蒙版只表示「抬到极限会露出来的区域」，**不区分材质**。里面既有外套布料，也有背包与身体；补绘时必须按邻近材质分别画，不能整块填一个颜色。

## 腕部重叠实验（实测）

| 重叠带 | -15° 空洞 | +15° 空洞 |
|---|---|---|
| 0px | 782 | 828 |
| 8px | 750 | 818 |
| 12px | 737 | 813 |
| 16px | 718 | 802 |
| 20px | 674 | 772 |
| 26px | 586 | 705 |
| 32px | 571 | 661 |

**结论：单靠加重叠关不掉腕部缝隙。** 32px 重叠仍有 571px 空洞，因为缺口在手掌摆动扫过的扇形区，不在接缝线上。
两种可选方案：手层补画「圆头腕关节」（推荐），或把手腕摆动限制在 ±8°。

## 已发现的缺陷

1. **手层覆盖不全**：手掌层只有 2,758 px，`torso_base` 在手的原位置仍残留约 **3,083 px** 像素。抬臂后原位置会出现「半只手」。
   → 需要重新抠手，或把残留像素一并归入手层。
2. **肩部/袖内衬无美术**：只有蒙版，没有可用的补绘画。
3. **背包挂件与手臂**：抬臂 -12°/-25° 时手臂扫过挂件（9,079 / 5,613 px），必须把挂件排在手臂**后面**。
4. **腕部重叠不足**（见上）。
