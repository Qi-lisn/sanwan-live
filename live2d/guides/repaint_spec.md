# 三万挥手补绘规格书（V0.2 标注版）

用途：交给美术（或另一个 AI）按此补绘。**本文件不包含任何补绘结果，只有标注与尺寸。**
基准：`live2d/layers_v01/00_reference/character_master_approved.png`（1052×1495 RGBA）

## 0. 坐标系与换算

| 用途 | 画布 | 换算 |
|---|---|---|
| 标注图 / 本文件坐标 | 1052×1495（native） | 1:1 |
| 实际交付 PSD / Cubism 工程 | 2104×2990（2x） | **×2**（native × 2 = 交付坐标） |
| 直播舞台显示 | 宽 720 × 高 1023 | native ÷ 1.461 |

- 本文件所有坐标都是 **native**；画到 2x 画布时乘以 2。
- 左右一律用 `screen_left` / `screen_right`（画面方向）。
  `screen_left` = 观众看到的左边 = 角色自己的右手。本次补绘对象就是 **screen_left 手臂**。

## 1. 三处核心补绘区域

| 区域 | native bbox | 尺寸 | 需补绘像素（60°/45°/±15° 实测） | 内容 |
|---|---|---|---|---|
| A 肩部底图 | (352, 366) – (476, 512) | 124×146 | 13,891 px（60° 时贴身体的空洞） | 肩、锁骨、腋下、外套肩线与袖窿 |
| B 肘部 | (286, 556) – (436, 700) | 150×144 | 5,803 px（45° 弯曲） | 上臂/前臂切口、肘内侧褶皱、袖管重叠 |
| C 手腕 + 手型 | (244, 716) – (384, 892) | 140×176 | 767 / 660 px（±15°） | 袖口过渡、腕部转动遮挡、三种手型 |

> bbox 只是标注范围，**实际补绘边界按运动轨迹取，不要机械限制在矩形内**。
> 红/蓝区分：红=必须新画（贴身体的空洞）；蓝=背景空洞，**不需要画**。

## 2. 保留 / 重绘 / 重叠

### 可直接保留（绿）
- 手臂袖子外轮廓、袖口罗纹、袖上鱼形印花
- 手掌、手指现有像素（张开手型可直接用）
- 背包、玩偶、躯干、腿部、头部全部原始像素

### 必须重新绘制（红）
1. 抬臂后露出的**肩部与腋下**（native 约 13,891 px）
2. **肘内侧**：切开后弯折处的褶皱与阴影（约 5,803 px）
3. **袖口与手掌之间**的过渡（约 700 px/侧）
4. 抬臂后可见的**袖管内衬**（原图没有，因为袖子贴着身体）

### 必须前后重叠
| 部件 | 关系 | 重叠量 |
|---|---|---|
| 上臂 / 前臂 | 前臂压在肘内侧上 | 8–10 px |
| 袖口 / 手掌 | 袖口压手腕 | 6–8 px |
| 肩部底图 / 躯干 | 肩部底图压在外套上 | 10–12 px |
| 手臂 / 背包挂件 | 手臂在前，挂件在后（抬臂时会遮住挂件，实测 12° 遮 9,079 px） | — |

## 3. 画布扩展（60° 的硬约束）

旋转实测（绕肩点 (403,411)）：

| 角度 | 手臂最左 x | 是否出画 |
|---|---|---|
| −12° | 173 | 否 |
| −25° | 87 | 否 |
| −40° | 7 | 贴边 |
| −60° | **−57** | **出画 57px** |

**结论：要支持 60° 抬臂，画布必须向左扩展 ≥ 100px**（57 出画 + 40 安全边）。
建议：母版改为 **1152×1495**（内容右移 100px），或直接在 2x 画布留 200px 左边距。

```
躯干/外套 → shoulder_fill → 背包 → 背包挂件 → sleeve_back → armL_upper
→ armL_fore → 袖口 → handL_* → 前发（如遮挡）
```

## 6. 补绘后能否实现 60° 抬臂？

**能，但不是只补肩肘腕就够。** 还有三个必须同时解决的问题：

1. **画布宽度**：60° 时手臂出画 57px，不扩展画布会被裁掉（见第 3 节）
2. **袖子内衬缺失**：抬臂 ≥40° 会看到袖管里面，原图完全没有这段
3. **背包挂件遮挡**：抬臂 12° 时手臂会扫过挂件区域（9,079 px），必须确认挂件在手臂后面，且挂件不需要补画被遮部分（因为是被遮，不是露空）

只补画肩、肘、腕而不做这三项，60° 抬臂会出现：**手掌被裁、袖内空洞、挂件盖在手臂上**。

## 7. 验收标准

补绘完成后，用同样的模拟脚本复跑：

- 肩 −60°：贴身体空洞 = **0 px**
- 肘 −45°：空洞 = 0 px
- 腕 ±15°：空洞 = 0 px
- 手臂最左 x ≥ 40（画布内留边）
