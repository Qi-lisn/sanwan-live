# 三万 Live2D 资产审计（V0.1）

基准：`live/character_v3.png`（1052×1495，RGBA，人物 bbox 25,10–978,1477）
用途：判断现有素材能否复用、缺什么、补画范围与母版规范。**本文件不含任何模型文件或骨骼数据。**

## 1. 现有 layers_ai 审计

目录：`assets/layers_ai/`（1086×1448，与基准**不是同一张渲染**）

| 文件 | 尺寸/内容 bbox | 判定 | 原因 |
|---|---|---|---|
| `base.png` | 1086×1448，人物 98.8% 高 | ❌ 不可复用 | 画布比例 0.750 vs 基准 0.704；缩放到基准后**面部均值差 53/255、50% 像素差>25** |
| `hair.png` | 353,1–814,571（仅一片前发） | ❌ 不可复用 | 同批渲染错位；且无后发/侧发/呆毛分层 |
| `eyes.png` | 177×78 | ❌ 分辨率不足 | 母版 2104 宽下眼区需 ≈700×300；现尺寸约为其 1/4 |
| `brows.png` | 160×63 | ❌ 分辨率不足 | 同上，且左右眉未分开 |
| `m_a.png` | 52×22（闭嘴） | ❌ 分辨率不足 | 母版嘴区需 ≈200×150 |
| `m_b.png` | 46×40（微张） | ❌ 分辨率不足 | 同上 |
| `m_c.png` | 76×66（张口） | ❌ 分辨率不足 | 同上 |
| `composite_m_*.png` | 合成预览 | ⚪ 仅参考 | 已肉眼验证错位，不能作为素材 |

**结论：`layers_ai` 全部不可直接复用**，只能作为「曾经尝试过 AI 拆层」的记录。
真正与基准对齐的只有两个派生层：`live/blink2.png`（闭眼）与 `live/mouth_open.png`（张嘴），它们来自同一张渲染，可用于**对齐参考**，但同样是整脸软蒙版，不能当独立部位层。

## 3. 需要补画的区域（原姿势遮盖）

| 区域 | 遮挡关系 | 补画要求 |
|---|---|---|
| 举起的左臂内侧 | V 字手横在脸前，挡着脸颊与刘海 | 手臂抬起后露出的**脸颊、刘海根部、耳前头发** |
| 左手手掌 | 只画了 V 字手指并拢的正反两面 | 张开手掌、握拳、指点三种手型 |
| 抱玩偶的右臂 | 整条前臂被玩偶挡住 | 玩偶后面的**前臂、手、袖口** |
| 海豹玩偶背面 | 只画了正面 | 背面、侧面、被手臂压住处的凹陷 |
| 背包背带下 | 肩带压住外套 | 肩带下面的**外套肩部、胸前衣料** |
| 背包背面 | 被身体挡住 | 包背面与身体之间的缝隙、包带延长段 |
| 抬起的左腿根部 | 裙摆盖住大腿根 | 裙下的**大腿上段、裙内衬** |
| 裙摆内侧 | 前片遮住后片 | 后片、内衬、腿部与裙的接触阴影 |
| 耳机下 | 耳罩压住头发 | 耳罩后的**头发**（耳机转动时不破） |
| 领口/下巴下 | 下巴遮住脖子 | 脖子全段、锁骨、衣领内侧 |

## 4. 标准站姿母版方案

保留：脸型、五官位置、发型与发饰、耳机、外套、背包、蓝色海豹玩偶、配色与画风。
调整：**把「V 字举臂 + 抬腿」的定格姿势改为可绑定的中立站姿**。

| 部位 | 原图 | 母版建议 |
|---|---|---|
| 左臂 | 高举、V 字手在脸前 | 自然下垂外展 **25–30°**，手掌张开朝内 |
| 右臂 | 抱玩偶、前臂被挡 | 同样外展 25–30°，**玩偶改为抱在身前偏左**，手臂完整可见 |
| 左腿 | 抬起、膝盖弯 | 双脚落地，与肩同宽，重心居中 |
| 右腿 | 支撑 | 直立，脚掌朝前 |
| 躯干 | 轻微侧倾 | 正面，肩线水平 |
| 头部 | 略偏右、闭眼笑 | 正面平视，**睁眼**（闭眼由参数控制） |
| 玩偶 | 抱在右臂上、挡手臂 | 抱在胸腹前，左右手臂都能绕到它后面 |

> 母版只做「一个姿势」，所有动作靠参数驱动，不再做整图像素形变。

## 5. PSD 规范

- **画布**：2104×2990（基准 1052×1495 的整 2 倍），RGBA，sRGB
- **锚点**：脚底中心固定 **(1052, 2870)**，四周留 40–60px 余量
- **人物高度**：占画布 92–96%（对应舞台显示宽 720 / 高 1023）
- **分组顺序**（从上到下即图层顺序，括号内为组内层数）：

```
00_ref            参考图（隐藏）
10_hair_back      后发、侧发（3–4）
20_body           躯干、腿、裙后片（8–10）
30_arm_R          右上臂/前臂/手（3–4）
40_plush          海豹玩偶、皇冠、鳍（3–5）
50_arm_L          左上臂/前臂/手（3–4）
60_backpack       包体、双肩带、挂件（4–6）
70_face           头、耳、脖、下颌（4）
71_eyes           左右眼白/瞳/睑、睫毛（6–8）
72_brows          左右眉（2）
73_mouth          闭/微张/张口（3）
74_hair_front     刘海、呆毛、发饰（4–6）
80_headphones     头梁、左右耳罩（3）
90_fx             星星、光效（2–4）
```

- **命名**：`L{两位序号}_{部位}_{子件}_{状态}`，例：
  `L71_eyeL_white`、`L71_eyeL_closed`、`L73_mouth_open`、`L50_armL_upper`
- 左右一律以**画面方向**为准（L=画面左侧），在文件头注明
- 每个可动部件四周留 **8–16px 透明边**，避免网格裁切
- 补画区域用同色系、同光向；阴影方向统一来自画面左上

## 6. 与 `docs/live2d-brief.md` 的冲突

| 项 | brief 原文 | 实际/问题 | 修订建议 |
|---|---|---|---|
| 画布 | 1920×1080 | 角色图是 1052×1495 竖图，按 16:9 画布做会被裁腿 | 模型画布 **2104×2990**；1920×1080 只是舞台，不是模型画布 |
| 人物高度 | 约 980px（90%） | 舞台实际显示高 **1023px**（hero 720 宽 × 1495/1052） | 改为「显示宽 720、高 1023」 |
| 脚底位置 | y≈1040 | 舞台 hero 底部在 y≈1049（bottom 26px） | 改为「脚底对齐舞台 y≈1049」 |
| 站位 | 水平居中 x≈960 | 舞台实际在 **left 42%**（x≈806） | 改为「画面偏左 42%，右侧留给点歌台」 |
| 朝向 | 正面略偏右 | 原图是**举 V 手、抬左腿**的动态定格 | 先做中立站姿母版（见第 4 节） |
| 参数表 | 只有 9 个 | 缺眼球、身体 Y/Z、眉毛、手臂、手、头发、裙摆 | 补全（见第 7 节） |
| 验收 | 「叠在 bg.jpg 上截图」 | 舞台是 HTML 合成，不是单张背景 | 改为「在 `stage_sing.html` 里截图核对」 |

## 7. Cubism 参数规范

| 参数 ID | 范围 | 驱动 |
|---|---|---|
| `ParamAngleX/Y/Z` | -30..30 | 头部转动/倾斜 |
| `ParamBodyAngleX/Y/Z` | -10..10 | 身体摆动 |
| `ParamBreath` | 0..1 | 呼吸 |
| `ParamEyeLOpen` / `ParamEyeROpen` | 0..1 | 眨眼 |
| `ParamEyeBallX` / `ParamEyeBallY` | -1..1 | 视线 |
| `ParamBrowLY` / `ParamBrowRY` | -1..1 | 眉毛 |
| `ParamMouthOpenY` | 0..1 | 口型（对接 TTS 音量） |
| `ParamMouthForm` | -1..1 | 嘴角（笑/撇嘴） |
| `ParamArmLA` / `ParamArmRA` | -1..1 | 左右手臂抬起 |
| `ParamHandL` / `ParamHandR` | -1..1 | 手腕/手型切换 |
| `ParamHairFront` / `ParamHairBack` | -1..1 | 头发摆动（物理输入） |
| `ParamSkirt` | -1..1 | 裙摆 |
| `ParamPlush` | 0..1 | 玩偶挤压 |

> **重要**：以上只是**命名规范**。写了参数名不等于模型已绑定——必须在 Cubism Editor 里完成网格（Mesh）、变形器（Deformer）、参数关键帧、物理（Physics）与动作（Motion），并导出 `.moc3` 才算完成。

## 8. 结论

1. 现有 `layers_ai` **全部作废**，不要在此基础上继续拼。
2. 需要一张**中立站姿母版**，按第 5 节规范分层出 PSD。
3. 补画重点是「被姿势遮挡的部位」——手臂内侧、玩偶背面、背包背带下、裙下腿部。
4. `docs/live2d-brief.md` 的尺寸规格与当前舞台不符，需按第 6 节修订。
5. 本轮不改播放器、不生成伪模型；等母版 PSD 到位再进入 Cubism 绑定。
