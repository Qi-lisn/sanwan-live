## 二、缺口统计

| 项 | 数值 |
|---|---|
| 前臂原位置空洞并集（-25/-40/-60） | **10,769 px** |
| 范围 | y 691–861，x 364–477 |
| 其中真正需要补画 | **4,894 px**（沿外套左缘的窄带 + 顶部融合带） |
| 其中应保持透明（背景） | **6,213 px** |

**关键判断**：手臂抬起后，左侧那一大片空白是背景，不是缺失的身体。
只有贴着外套/裙子左缘的一条带需要画——它原本被袖子挡住。

## 三、补什么

| 区 | 大致范围 | 内容 |
|---|---|---|
| A 外套左侧片 | (440,690)–(480,760) | 外套下摆左缘，接住肩部补绘的底缘，消除 y≈691 的横向"台面" |
| B 裙/胯边 | (430,760)–(480,849) | 裙子左缘与胯部，收口自然 |
| C 其余 | 左半边 | **不要画**，保持透明 |

顶部融合带（y 684–700）是为了让肩部补绘的下缘不出现直线切边，画的时候要顺着布纹过渡，不要留横线。

## 四、层级

```
背包体 → 躯干/外套 → 背包挂件 → 上臂 → 前臂 → 手
```

挂件必须在上臂/前臂之后被压住（抬臂时会挡住挂件）。

## 五、手部

已核对：`torso_base_with_shoulder.png` 中手部残留仅 **119 px**（多为边缘抗锯齿），
原 2,111 px 的"半只手"已并入 `hand_open_clean.png`，不会再出现悬空手掌。

## 六、验收标准（`forearm_fill.png`）

| 项 | 要求 |
|---|---|
| 尺寸/模式 | 1152×1495 RGBA，透明背景 |
| 蒙版覆盖 | ≥ 98%（4,896 / 4,894） |
| 蒙版外溢出 | ≤ 2% |
| 横向台面 | y 691 附近不得出现水平直线切边 |
| 背景 | 蒙版左侧保持透明，不得填成衣服 |
| 运动 | 0/-25/-40/-60° 时，蒙版内空洞 = 0 |
| 重复元素 | 不得复制口袋反光条、下摆罗纹 |
| 纹理 | 与原外套渐变、褶皱方向一致 |
